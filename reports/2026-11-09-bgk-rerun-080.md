# 2026-11-09: BGK rerun on HyperCloud 0.6.0 / HyperCloudCore 0.8.0 (IMEX fixes)

HyperCloudCore 0.8.0 contains the IMEX fixes of the code review: the published ARS(2,2,2) tableau, implicit sources
applied explicitly with explicit tableaus, and converting only tableaus without an implicit part. Rerun of the BGK part
of the 2026-10-28 study (reports/2026-10-29-rerun-078.md §6) with unchanged configs: density wave (static and Lagrangian
grid, Shepard/MLS volumes, with and without particle management, τ = 1e-4 and ∞), Sod (three methods incl. VK, static /
Lagrangian / Lagrangian + particle management, τ = 1e-5, 1e-3, 1e-2), Sod with conservation diagnostics, 2-D vortex
(with and without the ALE flux test patch). CPU, Float64.

- 97 cluster jobs on GPU nodes (`gpus=1 cpus=16`; the CPU partition was full, 97 jobs had waited 14 h on fair-share
  priority, and were cancelled). The GPU is not used: `tools/adapt_study.jl` runs on CPU arrays and the Sod pipeline
  jobs keep the CPU backend for comparability. Queue `cluster/queues/2026-11-09-bgk-080-gpu.txt`, job ids in
  `cluster/queues/logs/2026-11-09-bgk-080-gpu.log` (gitignored).
- All finished: 2172 RESULT lines (as in 0.7.8), 243/243 Sod pipeline runs OK (the VK run that crashed on 0.7.8,
  Lagrangian + adaptivity, τ = 1e-2, N = 100, now finishes), no crash, no time limit.
- Tables: `reports/2026-11-09-bgk-tables-080.md` (`julia tools/bgk_table.jl <results>`, a Julia port of
  tools/bgk_table.py that reproduces the 0.7.8 tables exactly; this container has no Python). Sod pipeline runs in `data/`.

## 1. ARS(2,2,2) is now consistent with ARS(2,3,3) in the stiff regime

Density wave, static grid, MLS volumes, τ = 1e-4, L1(ρ) against the Euler solution:

| N | 50 | 100 | 200 | 400 | 566 | 800 |
|---|---|---|---|---|---|---|
| ARS222MUSCL2, 0.7.8 | 1.74e-2 | 4.03e-3 | 1.04e-3 | 2.60e-4 | 1.46e-4 | 1.78e-4 |
| ARS222MUSCL2, 0.8.0 | 1.86e-2 | 4.53e-3 | 1.24e-3 | 5.43e-4 | 4.79e-4 | 4.60e-4 |
| ARS233MUSCL3, both | 1.12e-2 | 2.50e-3 | 7.56e-4 | 4.75e-4 | 4.56e-4 | 4.51e-4 |

- **ARS(2,3,3) results are bit-identical** between the versions in every wave and vortex row: only ARS(2,2,2) changed.
- With the corrected tableau, ARS(2,2,2) levels off at the same floor as ARS(2,3,3), ~4.5e-4. That floor is the model
  (BGK with τ = 1e-4 and 24 velocities against the Euler limit), not the discretisation. The old ARS(2,2,2) went below
  it (1.5e-4 at N = 566), i.e. it did not converge to the BGK solution the other scheme converges to: its smaller
  error against Euler was an inconsistency, now fixed. On the Lagrangian grid the same: 2.22e-4 → 5.11e-4 at N = 800.
- In the collisionless limit (τ = ∞, no implicit part) nothing changes; conservation (interior content) is unchanged
  except with Shepard volumes on the Lagrangian grid (−1.1e-5 → −3.4e-5, the known Shepard bias).
- The 2-D vortex (dominated by the model error, L1 ≈ 1.3–1.4) changes by ≤ 2 %.
- The ALE flux patch (per-velocity dissipation on moving grids, not in the library) still helps on the wave: N = 200,
  Lagrangian, L1 2.1e-3 → 6.1e-4 (local check before the runs).
